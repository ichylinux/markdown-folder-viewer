Open a Markdown file in Chrome

This extension renders local Markdown files and shows the file's folder on the left, with the real path in the address bar.

  1. On chrome://extensions, open this extension's Details and turn on Allow access to file URLs.
  2. Open a local .md file in Chrome (Ctrl+O, or a file:///… address).
  3. On the rendered file, click Remember this folder in the left pane and pick the folder that contains it. It is recorded automatically after that.

Saved folders are listed on the left and open with one click. Chrome does not reveal the location of a folder picked by the viewer, so the viewer does not offer a folder picker.
